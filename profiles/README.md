# Profils Hermes AgriAgent

Configuration des 6 profils Hermes (sans secrets).

## Profils

- `agri_orchestrateur/` — Orchestrateur (lecture seule + délégation)
- `agri_data/` — DataAgent (CRUD base)
- `agri_meteo/` — MeteoAgent (collecte météo)
- `agri_diag/` — DiagAgent (diagnostic maladies)
- `agri_vision/` — VisionAgent (analyse photos)
- `agri_alert/` — AlertAgent (détection alertes)
