## 📋 Description

**AgriAgent** est un système multi-agents qui aide les agriculteurs à :

- 🌾 **Suivre** l'état de leurs cultures parcelle par parcelle
- 🔬 **Diagnostiquer** les maladies et ravageurs
- 📊 **Historiser** les interventions, la météo et les récoltes
- 🔔 **Recevoir** des alertes actionnables
